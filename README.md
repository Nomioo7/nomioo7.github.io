## Pages
- `index.html`: home page
- `blog/compound-interest-guide/`
- `blog/mortgage-payment-guide/`
- `blog/bmi-and-calories-guide/`

## Publish on GitHub Pages
1. Replace `nomioo7` in every file with your GitHub username.
2. Create a repo named `nomioo7.github.io` and push these files to `main`.
3. Settings → Pages → Source: **Deploy from a branch** → `main` / root.
4. Site goes live at `https://nomioo7.github.io/`.
